# NIAN — AI Daily Companion

NIAN is a browser-based personal productivity companion designed to help users organize their day based on available time, priorities, and current situations.

It includes a daily planner, task tracker, focus sprint timer, reward points system, and a simple motivational system to make productivity more structured and enjoyable.

### Features

* Create a personalized daily plan
* Track daily, weekly, and monthly tasks
* Focus sprint timer
* Reward points system
* Responsive and modern UI
* Data persistence using localStorage
* Works directly in the browser with no backend required

### Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

NIAN was created as a personal project to explore web development, JavaScript functionality, and user-focused productivity design.
